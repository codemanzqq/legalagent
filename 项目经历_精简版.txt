【项目一】DataAgent - 企业级智能数据分析 Agent

项目简介：面向企业数据分析场景的 AI Agent 系统，Text-to-SQL 准确率 95%+，围绕"自然语言查询 -> SQL 生成 -> Python 深度分析 -> 智能报告输出"构建完整闭环。

技术实现：
- 基于 Spring Boot 3.x + Spring AI Alibaba Graph 搭建后端，实现 StateGraph 工作流编排与 16+ 节点调度
- 实现 Human-in-the-loop 人工反馈机制，支持用户在计划生成阶段干预与修正
- 运行时动态 LLM 路由，根据任务复杂度自动切换 Qwen-Max/Turbo 优化成本与效果
- 基于 pgvector/Milvus 实现 RAG 检索增强，支持业务术语语义召回与 Schema 映射
- 基于 LangChain Tool Calling Agent 实现 NL2SQL、Python 执行器、MCP 工具集成
- 使用 Docker Compose 管理 MySQL、向量数据库、Python 执行器容器，完成本地多服务联调与部署

【项目二】Policy Agent - 山东省智能政策咨询助手

项目简介：面向以旧换新补贴政策咨询的 RAG 问答系统，问答准确率 95%+，补贴计算准确率 100%，节省 60% 客服人力。

技术实现：
- 基于 Spring Boot 3.x + Spring AI 搭建后端，实现 RAG 核心链路（文档加载、切片、检索、生成）
- 实现运行时嵌入模型路由，根据文档类型与查询场景动态选择最优嵌入模型
- 基于 DashScope Embedding + PostgreSQL + pgvector 实现政策文档 RAG，支持混合检索与 CrossEncoder 重排
- 基于 Tool Calling Agent 实现补贴计算工具、发票/文件解析工具、联网搜索工具集成
- 独创 ToolFailurePolicyCenter 统一处理工具失败重试与兜底，无效调用率降低 40%
- 基于 Redis 实现会话事实缓存与多轮对话上下文管理，关键信息（价格、地区、型号）结构化存储供多轮复用
- 使用 Docker Compose 管理 PostgreSQL、Redis、MinIO 等依赖服务，高峰期可承载 500+ 并发咨询

【项目三】Legal RAG - 智能客服问答系统

项目简介：面向企业客服场景的 RAG 问答系统，检索召回率 96%+，问答准确率 95%+，缓存命中率>60%。

技术实现：
- 基于 FastAPI + Uvicorn 搭建异步后端，实现 SSE 流式响应与依赖注入
- 实现三阶意图路由（直达/检索/生成），简单问题直达模型降低 70% 响应延迟
- 基于 BGE-M3 + Milvus 实现稠密向量检索，融合 BM25 关键词与 RRF 排序算法
- 采用 Parent/Child Chunk 分层索引策略，召回后基于完整父文档片段生成回答
- 基于 BGE-Reranker-Large CrossEncoder 实现召回后精准重排序
- 使用 Redis 实现问答缓存（TTL 可配置），缓存命中率>60%
- 使用 Docker Compose 管理 MySQL、Milvus、Redis 等依赖服务，支持一键部署

【项目四】Recipe Planner - 智能食谱生成器

项目简介：面向个人饮食规划的 AI 应用，食谱不重复率 98%+，用户满意度 90%+，围绕"用户信息收集 -> AI 食谱生成 -> 聊天助手 -> PDF/Word 导出"构建完整闭环。

技术实现：
- 基于 Spring Boot 3.x + Spring Security + JWT 搭建后端，实现用户认证与 RBAC 权限控制
- 基于 Mifflin-St Jeor 公式计算用户每日热量需求，结合 Claude API 生成 1-30 天可定制个性化食谱
- 基于 PostgreSQL + JPA 实现用户数据、食谱记录、聊天历史持久化存储
- 实现上下文感知聊天助手，基于 Redis 存储对话历史，支持读取用户个人信息与当前食谱内容
- 基于 React 18 + TypeScript + Tailwind CSS 实现前端对话 UI、悬浮聊天窗口与响应式布局
- 集成 react-pdf/docx 实现食谱一键导出为 PDF 或 Word 格式
- 使用 Docker Compose 管理 PostgreSQL 数据库，支持本地开发与云端部署（Vercel/Railway）
